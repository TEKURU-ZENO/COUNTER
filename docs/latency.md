# Latency measurements

No measurements have been published yet.

This file is generated by `infra/scripts/latency_report.py` from timings the running system stores
(`call_turns` for LLM and speech timings, `webhook_events` for PayPal delivery). Earlier versions of
this page listed figures that were typed into a script rather than measured; they have been removed.

To produce real numbers: run calls against a deployment with an LLM configured and PayPal in sandbox
mode, then run

    python -m infra.scripts.latency_report --environment "<where you ran it>"
